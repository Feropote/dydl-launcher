# dydl

A personal learning project: a local Minecraft launcher written in Python.

## About

I'm building this launcher while learning Python and Git. It is made for me and my friends, not as a public product.

## Goals

- Run Minecraft locally from a custom launcher
- Support separate instances (builds), so different setups don't get mixed up
- Learn Python, project structure and version control along the way

## Status

Work in progress.
